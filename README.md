# Beamcove Community Health Files

> **The meta-repository for all Beamcove repositories** — Because even documentation needs documentation.

This special `.github` repository contains default community health files and templates that apply across all repositories in the Beamcove organization. Think of it as the organizational home base for contributor guidelines, issue templates, and all the other stuff that keeps our projects running smoothly.

## How This Works

Files in this repository automatically apply to all public repositories in the Beamcove organization that don't have their own versions of these files. 

**For example:**
- If a repository doesn't have a `CONTRIBUTING.md`, GitHub will use the one from this repository
- If a repository has its own `CODE_OF_CONDUCT.md`, that takes precedence over this one

**Learn more**: [GitHub Docs on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)

## Customizing for Your Repository

Need to override these defaults for a specific repository? No problem!

1. Copy the file you want to customize to your repository
2. Make your changes
3. Commit and push — your version now takes precedence

**Pro tip**: Only override when necessary. Using these defaults keeps our organization consistent and reduces maintenance burden.

## Making Changes

Want to update these community health files?

1. **Discuss first** — Open an issue to talk through proposed changes
2. **Make it count** — These files affect all our repositories, so changes should be well-considered
3. **Submit a PR** — Follow our own [contributing guidelines](CONTRIBUTING.md)
4. **Get review** — Changes require approval from maintainers
