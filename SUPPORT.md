```
┌─────────────────────────────────────┐
│   Do you have a question?           │
```

## 🐛 Bug Reports

Found a bug? Sorry about that! Here's how to report it:

1. **Check existing issues** — Someone might have already reported it
2. **Use our bug report template** — [Create a new issue](../../issues/new/choose)
3. **Provide details** — The more info, the faster we can fix it

**Expected response time**: We triage new issues within 1-3 business days

## ✨ Feature Requests

Got an idea for a new feature? Awesome!

1. **Check existing feature requests** — See if someone already suggested it (you can upvote!)
2. **Use our feature request template** — [Submit your idea](../../issues/new/choose)
3. **Explain the use case** — Help us understand *why* this would be valuable

**Expected response time**: We review feature requests weekly

## 🔒 Security Issues

**STOP!** If you've found a security vulnerability, **do not** open a public issue.

Instead, please report it privately:
- Use our [security advisory form](../../security/advisories/new)
- Or email: **security@example.com**

See our [Security Policy](SECURITY.md) for full details.

## 🆘 Getting Urgent Help

### What qualifies as urgent?

- **Security vulnerabilities** — Report via our security policy
- **Service outages** — Check our [status page](https://status.example.com) (if applicable)
- **Critical bugs in production** — Open an issue and label it `critical`

### What doesn't qualify as urgent?

- Questions about usage (use Discussions)
- Feature requests (they take time to implement)
- Bugs that don't cause data loss or security issues

**Please respect our time**: Not everything is an emergency. Overusing urgent channels means we can't respond quickly when things truly are critical.

## ❌ What We Can't Help With

We're awesome, but we're not magicians. We probably can't help with:

- Third-party integrations we don't maintain
- General programming questions (try [Stack Overflow](https://stackoverflow.com))
- Issues with your specific infrastructure or environment
- Homework assignments (nice try!)
- Debugging your entire application

**But we can help you help yourself!** Point us to specific error messages or issues with our software, and we'll do our best.

## 🎯 How to Ask Good Questions

Want a helpful answer? Ask a helpful question!

### Good questions include:

✅ What you're trying to accomplish  
✅ What you've already tried  
✅ Specific error messages (full text, not just "it doesn't work")  
✅ Relevant code snippets or configuration  
✅ Your environment (OS, version, etc.)  

### Less helpful questions:

❌ "It's broken, help!"  
❌ Screenshots of code (paste the text instead)  
❌ "I have a bug" (without details)  
❌ Asking the same question in multiple places  

**Remember**: We want to help you, but we need information to do so!
